## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/<your-username>/java.git
cd java
```

### Compile a Program

```bash
javac FileName.java
```

### Run a Program

```bash
java FileName
```

Replace `FileName` with the name of the Java program you want to execute.
